# Cloud-Native GitOps & Microservices Automation Platform on AWS EKS

## Project Overview

A hands-on learning project to explore cloud infrastructure automation,
containerized microservices, Kubernetes deployments, GitOps, CI/CD,
and monitoring on AWS.

## Project Status

Phase 1: Development environment setup.

## Technology Stack

- AWS
- Terraform
- Docker
- Kubernetes (Amazon EKS)
- Helm
- GitHub Actions
- Argo CD
- Prometheus
- Grafana
